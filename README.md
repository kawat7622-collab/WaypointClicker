# Waypoint Clicker

Waypoint Clicker is a lightweight Roblox tool for **capturing positions in the world by clicking** and teleporting back to them whenever you want.

Waypoint Clicker is built to be simple, fast and clean, with a modern Liquid Glass interface. Click anywhere in the world to save a waypoint, then copy, teleport to or delete it from the menu.

## Status

Waypoint Clicker is actively maintained. The current version is **v1.2.1**. Bug reports, suggestions and questions are welcome in the [Support Server](https://discord.gg/xNrrEjKwrU).

## Features

- Capture waypoints by clicking anywhere in the world
- Teleport to any saved waypoint with one click
- Copy waypoint coordinates to your clipboard
- Delete single waypoints or clear them all at once
- Live status and waypoint counter on the main page
- Minimize the menu to a small draggable icon
- Toggle the menu at any time with the **K** key
- Custom ingame notifications

## Script

To use Waypoint Clicker, just run the following code (or copy the code from `Main.lua`) into a supported executor.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/kawat7622-collab/WaypointClicker/main/Main.lua"))()
```

## How to use

1. Run the script. The menu opens in the middle of the screen.
2. Press **Start** on the Main page to begin recording.
3. Click anywhere in the world to drop a waypoint. A small marker shows where it was placed.
4. Press **Stop** when you are done.
5. Open the **Waypoints** page to **Copy**, **Teleport** to or **Delete** your waypoints.

| Control | Action |
| --- | --- |
| 🔴 Red button | Close the menu |
| 🟡 Yellow button | Minimize to a small icon |
| 🟢 Green button | Center the menu on screen |
| **K** | Show or hide the menu |
